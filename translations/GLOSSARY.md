# Translation Glossary & Style Guide

To maintain consistency across COSYgames, please follow this glossary for common UI terms and style guidelines.

## Style Guidelines

1. **Informal Register**: Always use the informal register across all languages:
   - French: `tu`
   - Spanish: `tú`
   - German: `du`
   - Italian: `tu`
   - Russian: `ты`
   - Greek: `εσύ`
2. **Game Names**: Keep game names untranslated (e.g. *Last Letter*, *Lucky Numbers*, *Hot Seat*, *Story Weaver*).
3. **Emojis & Symbols**: Do not alter or translate emojis or symbols (`▶`, `✓`, `↺`, `👂`, `📣`, `🃏`).
4. **Imperative Buttons**: Use short, direct imperative forms for buttons and action controls (e.g. "Rejouer", "Inizia", "Starten").
