## Critical issues (must fix before launch)
- [ ] Navigation broken or unusable on mobile
- [ ] Primary game action (start, play, restart) hard to find or use
- [ ] Text too small / poor contrast
- [ ] Buttons/inputs too small or too close together
- [ ] Horizontal overflow / clipped content on small screens
- [ ] Missing focus states / keyboard navigation broken
- [ ] Feedback only via color (no text/icon/pattern)
- [ ] Missing loading / error / empty states for key flows
- [ ] Game controls unusable with keyboard or on touch screens
- [ ] Game state not saved or not resumable

## High priority
- [ ] Long game titles, instructions, or translations break layout
- [ ] Game feedback (win/lose/hint) unclear or too slow
- [ ] Score, streak, or progress not visible or not saved
- [ ] Inconsistent component behavior across games
- [ ] Images/assets too heavy or slow on mobile
- [ ] Timed interactions inaccessible to users who need more time

## Medium / Low
- [ ] Visual hierarchy unclear
- [ ] Too many similar-looking game cards or panels
- [ ] Overuse of decorative effects (gradients, glass, etc.)
- [ ] Inconsistent spacing / typography
- [ ] Instructions or help text difficult to find or understand
